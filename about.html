About Lorius Scripts

Lorius Scripts started with a simple idea: free Roblox scripts shouldn't be hidden behind key systems, shady link shorteners, or paywalls. Here you get a clean library of tested scripts for popular games — copy or download them in one click and get back to playing.

Every script in the library is described honestly and kept up to date with game patches. If a script stops working, it gets fixed or removed. And if your favorite game is missing, the suggestions page is the fastest way to get it added.

Lorius Scripts is connected to our YouTube channel, where you'll find step-by-step tutorials showing how to use each script — perfect if you're new to executors or just want to see a script in action before trying it yourself.
